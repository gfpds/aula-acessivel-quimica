# AulaAcessível — Módulo Química v4

Protótipo acadêmico de um gerador de roteiros inclusivos para aulas de Química.

## Como abrir

### Jeito mais simples
Abra o arquivo `index.html` no navegador.

### No Windows
Dê dois cliques em `INICIAR_AULA_ACESSIVEL_WINDOWS.bat`.
Ele tenta abrir um servidor local em `http://localhost:8000`.

### No Linux/Mac
Abra o terminal na pasta do projeto e execute:

```bash
./iniciar_aula_acessivel_linux_mac.sh
```

ou:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Como usar

1. Escolha um modelo pronto da Biblioteca IFSC.
2. Revise as barreiras da aula.
3. Gere apoios e ajuste somente se quiser.
4. Use as saídas: painel projetável, roteiro do aluno, orientação do professor, lista de placas/cards e checklist.

## Observação

O protótipo funciona sem internet, sem login e sem exigir celular dos alunos.
A tecnologia apoia o professor no planejamento; os apoios físicos/projetáveis ajudam a turma durante a aula.

## Base curricular

Os modelos iniciais foram organizados a partir do PPC do curso Técnico Integrado em Laboratório de Ciências da Natureza do IFSC São José, com foco em Química 1 a 6 e Laboratório de Química 1 a 3.
